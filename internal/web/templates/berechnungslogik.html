Strom (PV-Netzbezug-Zuteilung)

Netzbezug wird sequenziell zugeteilt: zuerst Wohnung 2 (gedeckelt auf ihren eigenen Verbrauch), dann die Wärmepumpe auf den verbleibenden Netzbezug, dann die Wallboxen auf den danach noch verbleibenden Netzbezug. Der Rest zählt implizit zu Wohnung 1 - keine eigene Kostenposition. Die Wallbox-Stufe ist rein informativ (keine eigene Wohnungs-Zuteilung, kein eigener Wallbox-Tarif), läuft aber über dieselbe Deckelung wie Wohnung 2/Wärmepumpe, damit ihr Wert konsistent zum übrigen Netzbezug bleibt.

Netzbezug_Gesamt = Verbrauch(strom_gesamt)

W2_Anteil_kWh      = min(Netzbezug_Gesamt, Verbrauch(strom_wohnung2))
Rest1              = Netzbezug_Gesamt - W2_Anteil_kWh
WP_Anteil_kWh      = min(Rest1, Verbrauch(strom_waermepumpe))
Rest2              = Rest1 - WP_Anteil_kWh
Wallbox_Anteil_kWh = min(Rest2, Verbrauch(strom_wallbox))

Kosten_Strom_W2  = W2_Anteil_kWh * Strompreis
Kosten_WP_gesamt = WP_Anteil_kWh * Strompreis        (Basis für Heizungskosten, siehe unten)
Kosten_Wallbox   = Wallbox_Anteil_kWh * Strompreis   (rein informativ)

Bei PV-Überschuss (Netzbezug_Gesamt = 0) sind alle 3 Kosten 0. Alle Anteile über min() gedeckelt, nie negativ.

Heizung/Warmwasser (konfigurierbarer Split, Default 70/30)

Die Wärmepumpen-Stromkosten (siehe oben) werden nach Wärmemengenzähler-Verhältnis und Wohnungsgrößen-Verhältnis auf beide Wohnungen verteilt. Die Gewichtung wird pro Ablesung gewählt - 70/30, 60/40 oder 50/50 - und bleibt für diese Periode eingefroren.

Ratio_Waerme_W1  = Verbrauch(waerme_wohnung1) / (Verbrauch(waerme_wohnung1) + Verbrauch(waerme_wohnung2))
Ratio_Waerme_W2  = Verbrauch(waerme_wohnung2) / (Verbrauch(waerme_wohnung1) + Verbrauch(waerme_wohnung2))
Ratio_Flaeche_W1 = qm_W1 / (qm_W1 + qm_W2)
Ratio_Flaeche_W2 = qm_W2 / (qm_W1 + qm_W2)

Kosten_Heizung_W1 = Kosten_WP_gesamt * (Gewichtung_Waerme * Ratio_Waerme_W1 + Gewichtung_Flaeche * Ratio_Flaeche_W1)
Kosten_Heizung_W2 = Kosten_WP_gesamt * (Gewichtung_Waerme * Ratio_Waerme_W2 + Gewichtung_Flaeche * Ratio_Flaeche_W2)

Sind in einer Periode beide Wärmeverbräuche 0 (z.B. Sommer, Wärmepumpe lief nur für Warmwasser), fällt die Wärme-Ratio auf eine hälftige Verteilung zurück statt den Kostenanteil verschwinden zu lassen. qm_W1/qm_W2 kommen von der Stammdaten-Seite - aktuelle Einzelwerte, nicht pro Ablesung eingefroren (anders als Strompreis/Personen unten).

Wasser (Frischwasser + Abwasser)

Der Verbrauch für die Warmwasseraufbereitung wird nach dem Personenverhältnis der jeweiligen Ablesung auf beide Wohnungen umgelegt, bevor die Frischwasserkosten berechnet werden. Abwasser wird in gleicher Menge wie Frischwasser angenommen - es gibt keinen separaten Abwasserzähler.

WW_Anteil_W1 = Verbrauch(wasser_warmwasseraufbereitung) * Personen_W1 / (Personen_W1 + Personen_W2)
WW_Anteil_W2 = Verbrauch(wasser_warmwasseraufbereitung) * Personen_W2 / (Personen_W1 + Personen_W2)

Frischwasser_W2 = Verbrauch(wasser_wohnung2) + WW_Anteil_W2
Frischwasser_W1 = (Verbrauch(wasser_gesamt) - Verbrauch(wasser_wohnung2) - Verbrauch(wasser_warmwasseraufbereitung)) + WW_Anteil_W1

Abwasser_W1 = Frischwasser_W1
Abwasser_W2 = Frischwasser_W2

Kosten_Frischwasser_X = Frischwasser_X * Frischwasserpreis
Kosten_Abwasser_X     = Abwasser_X * Abwasserpreis

Sind in einer Periode beide Personenzahlen 0 (z.B. leere Felder, Leerstand), fällt der Warmwasseraufbereitung-Anteil auf eine hälftige Verteilung zurück statt zu verschwinden.

Einspeisevergütung (PV)

Rein informativ, unabhängig von der Kostenverteilung oben - keine Wohnungs-Zuteilung, da der Einspeisezähler haus-weit misst.

Einspeisevergütung = Verbrauch(strom_einspeisung) * Einspeisung_Preis

Fixkosten/Grundgebühren

Die 14 festen Kostenpositionen (Grundsteuer, Wohngebäudeversicherung, Deichbeiträge, Abfallwirtschaft, Grundpreise Strom/Wasser/Abwasser/Internet, Wärmepumpen-Wartung) werden getrennt von Strom/Heizung/Wasser berechnet, auf der monatlichen Fixkosten-Eingabe. Jede Position hat pro Jahr einen Typ:

Monatswert("jährlich")  = Jahreswert / 12                       (aus den Stammdaten, im Formular nicht editierbar)
Monatswert("monatlich") = expliziter Wert der Fixkosten-Eingabe  (fehlt er, z.B. nach Typwechsel:
                                                                   letzter_bekannter_Jahreswert / 12, sonst 0)

Die Aufteilung auf Wohnung 1/2 hängt von der je Position/Jahr gewählten Berechnungslogik ab:

Je Wohneinheit          : 50 / 50
Je anteiliges Flurstück : flurstueck_W1 / (flurstueck_W1 + flurstueck_W2)   (Stammdaten)
Je anteilige Wohnungsgröße : qm_W1 / (qm_W1 + qm_W2)                        (Stammdaten)
Je Anzahl Personen      : Personen_W1 / (Personen_W1 + Personen_W2)         (aus der Fixkosten-Eingabe)

Sind bei "Je anteiliges Flurstück"/"Je anteilige Wohnungsgröße"/"Je Anzahl Personen" beide Werte 0, fällt die Aufteilung auf hälftig zurück statt zu verschwinden - gleiche Regel wie bei der Heizungs-Wärme-Ratio oben. Jede Position wird einzeln je Wohnung kaufmännisch gerundet, siehe Rundung unten.

Rundung

Jede Kostenposition (Strom, Heizung/Warmwasser, Frischwasser, Abwasser, jede der 14 Fixkosten-Positionen) wird einzeln je Wohnung kaufmännisch auf Cent gerundet (0,5 Cent immer aufgerundet), erst nach der vollständigen Berechnung mit float-Genauigkeit. Die angezeigte Gesamtsumme je Wohnung kann dadurch um 1-2 Cent von der rechnerisch exakten Summe abweichen - das ist akzeptiert, es gibt keinen Korrekturmechanismus.

Preise & Personenzahl

Es gibt kein zentrales Preishistorie-Konzept: Strompreis, Frischwasser-, Abwasser- und Einspeisung-Preis, Personenzahl je Wohnung und die Heizungs-Gewichtung werden direkt bei jeder monatlichen Ablesung erfasst (nicht separat versioniert). Ein einmal berechneter Monat bleibt dadurch automatisch eingefroren, auch wenn sich diese Werte später ändern.

Die Fixkosten-Eingabe hat ihre eigene, unabhängige Personenzahl je Wohnung (ebenfalls pro Monat eingefroren) - sie muss nicht mit der Personenzahl der Ablesung übereinstimmen, falls sich die Belegung zwischen zwei Ablesungen ändert.

Wohnungsgröße und Flurstücksgröße sind keine monatlichen Werte mehr: sie werden auf der Stammdaten-Seite gepflegt und wirken als aktuelle Einzelwerte sofort auf alle Monate - nicht eingefroren.

Fehlerbehandlung bei Zähleranomalien

Reine Warnhinweise, kein hartes Blockieren:

  • Negativer Verbrauch (neuer Stand kleiner als Vorstand): Warnung, Speichern bleibt möglich.
  • Ausreißer: Warnung, wenn der Verbrauch eines Zählers um mehr als ±50% vom Durchschnitt seiner letzten 3 Ablesungen abweicht (bei weniger als 3 Vorwerten kein Check).
  • Fehlende Ablesung (Lücke über 1 Monat): Hinweis "Verbrauch über X Monate", Berechnung läuft automatisch über den längeren Zeitraum.
